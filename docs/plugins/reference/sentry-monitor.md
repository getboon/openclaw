# Sentry Monitor plugin

Forward error-bearing OpenClaw lifecycle events to Sentry (model calls, agent turns, tool calls, message deliveries, subagents, cron runs, abnormal session ends) plus node-level uncaught exceptions / unhandled rejections.

## Distribution

- Package: `@openclaw/sentry-monitor`
- Install route: included in OpenClaw
